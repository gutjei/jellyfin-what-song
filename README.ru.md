# What Song? для Jellyfin 10.11.11

[English](README.md)

Поставьте фильм или серию на паузу. Плагин читает название песни и исполнителя из файла рядом с видео. В Jellyfin Web карточка обновляется после перемотки и исчезает при продолжении просмотра. Обработчик работает с локальными адаптерами плееров через события Jellyfin, без привязки к имени MPV или VLC.

В нативных клиентах сервер отправляет стандартное сообщение `DisplayMessage`, если клиент поддерживает его и сообщает серверу паузу и позицию. В Android TV это краткое системное уведомление, а не постоянная веб-карточка. Требуется рабочее WebSocket-соединение с сервером. Продолжительность и оформление задаёт клиент; протокол не позволяет убрать уже показанное уведомление при продолжении просмотра. Поддержка сверена с исходниками Android TV; проверка на физическом телевизоре отдельно необходима.

**Внешние VLC/MPV на Android TV.** Когда Jellyfin открывает отдельное приложение через Android Intent, оно не сообщает серверу промежуточные паузы и перемотки. В штатном Android TV передаётся только результат после возврата из внешнего плеера. Серверный плагин не может показать песню на такой паузе. Для этого нужна интеграция с самим внешним плеером или изменение телевизионного клиента. Наличие VLC/MPV как движка внутри клиента и запуск отдельного приложения — разные сценарии.

## Установка

1. Откройте **Панель управления → Плагины → Репозитории → Добавить**. Назовите репозиторий `What Song?` и вставьте адрес манифеста:

   ```text
   https://raw.githubusercontent.com/gutjei/jellyfin-what-song/main/manifest.json
   ```

2. На вкладке **Каталог** найдите **Song Pause**, установите его и перезапустите сервер Jellyfin.
3. Обновите страницу Jellyfin Web. Положите файл песен рядом с видео и поставьте воспроизведение на паузу. Плагин сам подключает скрипт к встроенному веб-клиенту при загрузке страницы.

**Сборка для проверки (1.3.0.0).** Скачайте артефакт `SongPause` из успешного запуска [Build](https://github.com/gutjei/jellyfin-what-song/actions/workflows/build.yml) или соберите проект и выполните `python tools/package.py`. ZIP создаётся в `dist/` и не хранится в Git. Каталог плагинов остаётся на последней опубликованной версии до загрузки нового пакета в релиз и публикации записи каталога.

**Установка из ZIP.** Распакуйте DLL из `SongPause_1.3.0.0.zip` в подпапку `SongPause_1.3.0.0` каталога плагинов сервера и перезапустите Jellyfin. Для удаления используйте страницу плагина в панели управления. Если раньше вы добавляли скрипт в `index.html` и строку `SongPause` в `config.json` вручную, эти записи можно убрать.

## Jellyfin Media Player

Приложение должно загружать веб-клиент с вашего сервера Jellyfin. Если используется встроенная в приложение копия веб-клиента, запустите Jellyfin Media Player с параметром `--force-external-webclient`. После обновления плагина перезапустите приложение. Карточка появляется поверх MPV на паузе и обновляется после перемотки.

## Музыкальные субтитры

Для `Фильм.mkv` создайте рядом файл `Фильм.songs.json`. Для сериала файл принадлежит конкретной серии, например `Сериал S01E02.songs.json` рядом с `Сериал S01E02.mp4`. Если у фильма несколько монтажных версий, используйте имя соответствующего видеофайла.

```json
{
  "version": 1,
  "songs": [
    { "startMs": 5000, "endMs": 20000, "artist": "Тихий берег", "title": "Первый снег" }
  ]
}
```

Формат — JSON в UTF-8 размером до 1 МиБ. Поля чувствительны к регистру. `startMs` и `endMs` — целые миллисекунды от начала конкретной версии видео. Начало включено, конец исключён. Интервал должен начинаться с нуля или позже и иметь положительную длительность. Название обязательно, исполнителя можно опустить. При наложении интервалов видны все соответствующие песни в порядке записи. В промежутках и при отсутствии файла плеер скрывает карточку. Некорректный файл пропускается целиком, причина записывается в журнал сервера. Файл перечитывается при следующей паузе или перемотке на паузе.

**Быстрая проверка.** Скопируйте [Demo.songs.json](examples/Demo.songs.json) рядом с видео длительностью более 32 секунд и замените `Demo` именем видео без расширения. На 10-й секунде появится «Тихий берег — Первый снег», на 19-й будут видны две песни, а на 32-й карточка исчезнет.

## Сборка из исходников

Из корня репозитория с установленным .NET 9 SDK выполните:

```sh
node --test tests/song-pause.test.cjs
dotnet test tests/SongPause.Tests.csproj -c Release
dotnet publish Jellyfin.Plugin.SongPause.csproj -c Release -o dist
```

Тесты моделируют контракты плееров и серверных сессий: паузу, перемотку, возобновление, устаревшие ответы, несколько клиентов и выбор монтажной версии. Они не заменяют запуск Android TV/VLC/MPV на устройстве. Веб-клиент продлевает регистрацию своего оверлея каждые 30 секунд; она действует 90 секунд и предотвращает дублирование серверным уведомлением. Сервер не использует расчётную позицию автоматического таймера Jellyfin для определения паузы.

Если нативный клиент не показывает песню, проверьте наличие `DisplayMessage` в `SupportedCommands`, `SupportsRemoteControl=true` и реальных отчётов `IsPaused`/`PositionTicks` в его сессии. При отсутствии поддержки в отладочном журнале плагина появляется сообщение `cannot receive DisplayMessage`.

Клиентский скрипт встроен в DLL. Название песни запрашивается через авторизованный маршрут `GET SongPause/{sourceId}/songs?positionMs=…`. Сервер самостоятельно определяет путь по идентификатору доступного пользователю фильма или эпизода.

Подход с файлом рядом с видео и карточкой на паузе основан на [JRay](https://gitea.tourolle.paris/dtourolle/jRay/src/branch/master/README.md). Расширение получает активную версию видео и позицию через [менеджер воспроизведения Jellyfin Web 10.11.11](https://github.com/jellyfin/jellyfin-web/blob/v10.11.11/src/components/playback/playbackmanager.js).

## Упаковка релиза

`python tools/package.py "Описание изменений"` создаёт ZIP и предварительный `manifest.json` в игнорируемой папке `dist/`. Корневой каталог не изменяется. Сначала загрузите ZIP в GitHub Release с тегом `v<версия>` и проверьте ссылку и контрольную сумму. Затем перенесите `dist/manifest.json` в корень и закоммитьте только каталог. ZIP, DLL и результаты сборки в Git не добавляются. Ссылки прежних версий закреплены за историческим коммитом, поэтому удаление ZIP из текущего дерева не ломает их установку.
